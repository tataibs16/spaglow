# Spa Glow — The Skin Experience

Landing page oficial do evento Spa Glow, com o layout V13 e as fotografias da identidade visual.

## Estrutura
- `index.html`: conteúdo da landing page.
- `styles.css`: identidade visual e responsividade.
- `script.js`: interações e validações do formulário.
- `assets/`: imagens, logotipo e favicons.

## Publicação
Este é um site estático. Para publicar via GitHub Pages, abra **Settings → Pages** e escolha a branch `main` e a pasta `/ (root)`.

## Importante
O formulário ainda é demonstrativo: **não envia inscrições reais**. O Asaas, a cobrança de ingressos e o contador de vagas em tempo real **não estão integrados**. Configure estes recursos e os dados definitivos do evento antes de divulgar a página para vendas.
